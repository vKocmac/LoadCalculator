# LC-UI-2026 — Σύστημα εμφάνισης (LoadCalculator και συγγενικά εργαλεία)

Πηγή αλήθειας για την εμφάνιση του `index.html` (HVAC Load Calculator) και για κάθε
άλλο εργαλείο που πρέπει να μοιάζει με αυτό (π.χ. υπολογισμός αντλιών).
Σχέδιο (canvas): https://claude.ai/artifact/Tjm1T1P7SqnMy3EGfzFfMu (ιδιωτικό — χρειάζεται share).

Ο κώδικας αναφοράς είναι μέσα στο `index.html`:
- CSS: όλο το `<style>` που ξεκινά με `/* ===== LC-UI-2026 light theme`.
- JS καθοδήγησης: το τελευταίο `<script>` που ξεκινά με `/* ===== LC-UI-2026 guided flow`.

---

## 1. Αρχές

1. **Φωτεινό θέμα.** Γκριζογάλαζο φόντο σελίδας, λευκές κάρτες, πεδία με δικό τους γέμισμα.
   Ποτέ «ενιαία ασπρίλα»: σελίδα ≠ κάρτα ≠ πεδίο, τρία διακριτά επίπεδα.
2. **Φαίνεται πού δουλεύεις.** Η ενότητα με το ενεργό πεδίο βάφεται ολόκληρη
   (απαλό tint + περίγραμμα accent)· το ίδιο το πεδίο παίρνει παχύ περίγραμμα και δαχτυλίδι.
3. **Σε παίρνει από το χέρι.** Αριθμημένες ενότητες, μπάρα προόδου, κουμπί «Επόμενο: …»
   στο τέλος κάθε ενότητας. «Ελεγμένη» = ο χρήστης πάτησε «Επόμενο» (όχι αυτόματα,
   γιατί τα πεδία έχουν ήδη προεπιλογές).
4. **Φόρμα αριστερά, όλα τα υπόλοιπα σε μία στήλη δεξιά** (400 px). Η μεσαία στενή στήλη
   με άδειο χώρο κάτω απορρίφθηκε.
5. **Η εμφάνιση δεν αγγίζει ποτέ τους υπολογισμούς.** Κρατάμε όλα τα `id`, τύπους στοιχείων
   και τη δομή «label + input μέσα στο ίδιο `div`». Νέα συμπεριφορά μπαίνει σε ξεχωριστό
   script που μόνο διαβάζει το DOM.

## 3. Διάταξη

```
┌ header (.hero): τίτλος · υπότιτλος · «Τυπική χρήση» · Γλώσσα (δεξιά)      ┐
├ tabs (segmented): Φορτία | Ψυχρομετρία                                    ┤
├──────────────── φόρμα (1fr) ────────────────┬──── δεξιά στήλη 400px ─────┤
│ μπάρα προόδου (sticky)                      │ Έργο & χώροι, PDF           │
│ [1] Ενότητα …                               │ Αποτέλεσμα + Υπολογισμός    │
│ [2] Ενότητα …                               │ Έλεγχοι εισόδων             │
│ …                                           │ Γρήγορες ενέργειες          │
│                                             │ Παραδοχές ▸ · Τύποι ▸       │
└─────────────────────────────────────────────┴─────────────────────────────┘
```
- ≥1120px: δύο στήλες, κάθε στήλη με δικό της scroll (`max-height: 100vh`).
- <1120px: μία στήλη, πρώτα η φόρμα και μετά η δεξιά στήλη.
- ≤980px: σταθερή μπάρα αποτελέσματος κάτω (`.lc-mbar`) με το σύνολο και «Ανάλυση ↑»·
  τα βήματα της μπάρας προόδου γίνονται οριζόντιο scroll.
- ≤768px: πεδία 48px ύψος, κουμπί «Επόμενο» σε όλο το πλάτος.

## 4. Components

**Κάρτα ενότητας (`.section` με `h2`)**
- Λωρίδα τίτλου `--surface-2`, αριθμός σε κουτάκι 28px μέσω CSS counter (`h2::before`),
  ετικέτα κατάστασης δεξιά μέσω `h2[data-chip]::after`.
- Καταστάσεις: `todo` (αριθμός με περίγραμμα, «Προεπιλογές»), `.lc-active` και
  `:focus-within` (tint + 2px accent + δαχτυλίδι 4px, λωρίδα `--accent-soft`, πεδία λευκά,
  «Συμπληρώνεις»), `.lc-done` (πράσινο ✓, «Ελέγχθηκε»).
- Φωλιασμένη ενότητα (π.χ. Συσκευές): χωρίς κάρτα, μόνο διαχωριστική γραμμή και
  κεφαλαίο υπότιτλο.

**Πεδία (`input`, `select`)**
| Κατάσταση | Εμφάνιση |
|---|---|
| κανονικό | `--field` γέμισμα, 1px `--field-line`, εσωτερική σκιά, 44px ύψος |
| focus | λευκό, 2px `--accent`, δαχτυλίδι 4px `--accent-ring`, η ετικέτα γίνεται accent |
| disabled / υπολογισμένο | λευκό, 1px διακεκομμένο `#B7C2CE`, κείμενο `--muted` |
| σφάλμα (για μελλοντική χρήση) | λευκό, 2px `--err`, μήνυμα κάτω σε `--err` |
Αριθμοί σε monospace. Τα `select` έχουν δικό τους βελάκι (SVG στο CSS).

**Κουμπιά:** `.primary` = γέμισμα accent, λευκό κείμενο. `.ghost`/απλό = λευκό με περίγραμμα.
Ελάχιστο ύψος 44px (48px σε κινητό).

**Αποτέλεσμα:** `.kpi-main` = απαλό accent, μεγάλος αριθμός σε mono.
`.rowline` = όνομα αριστερά, τιμή mono δεξιά. `.warn`/`.good` = πλαίσια με απαλό φόντο
(όχι μόνο αριστερή μπάρα).

**Γραφήματα canvas** που ζωγραφίζουν ανοιχτόχρωμο κείμενο μένουν σε σκούρο πλαίσιο
(`--chart-bg`). Έτσι δεν χρειάζεται να αλλάξει ο κώδικας σχεδίασης.

## 5. Guided flow script (`LC-UI-2026 guided flow`)

Αυτόνομο IIFE στο τέλος του `<body>`. Προϋποθέσεις στο HTML:
- container φόρμας με `id="loadsMain"` και ενότητες ως άμεσα παιδιά `.section > h2`.
- κουμπί υπολογισμού `#btnCalc`, αποτέλεσμα `#result .kpi-main b`, γλώσσα `#Lang`.

Τι κάνει: προσθέτει τη μπάρα προόδου (`.lc-rail`), το «Επόμενο» σε κάθε ενότητα
(`.lc-next`), το «Απομένουν N ενότητες» κάτω από τον Υπολογισμό, και την μπάρα κινητού.
Κρατά πρόοδο ανά χώρο (κλειδί: το όνομα του επιλεγμένου χώρου). Δεν καλεί καμία
συνάρτηση υπολογισμού και δεν γράφει σε πεδία.

Κείμενα: δεν περιέχουν ποτέ « / », γιατί το `collapseBilingualPairs()` του site
ξαναγράφει όσα στοιχεία έχουν « / » (και θα έσβηνε εσωτερικά στοιχεία).

## 6. Πώς το εφαρμόζεις σε άλλο εργαλείο (π.χ. αντλίες)

1. Πάρε baseline των αποτελεσμάτων **πριν** αλλάξεις οτιδήποτε (βλ. §7· προσάρμοσε
   τα `OUT_IDS` και τα σενάρια του `capture.py` στα ids του εργαλείου).
2. Αντέγραψε το CSS block και το guided-flow script. Βάλε `id` στο container της φόρμας
   και φρόντισε κάθε ενότητα να είναι `.section` με `h2` πρώτο παιδί.
3. Άλλαξε μόνο HTML δομή/κλάσεις και CSS. Μην μετακινείς `input` έξω από το `div` της
   ετικέτας του, μην αλλάζεις `id`, `type`, `value`, `option value`.
4. Γραφήματα: αν ζωγραφίζουν ανοιχτό κείμενο, κράτα σκούρο φόντο (`--chart-bg`).
5. Τρέξε ξανά capture + compare: πρέπει να βγαίνει `0 differences`.
6. Δουλειά σε branch → PR. Επαναφορά = κουμπί **Revert** στο PR.

## 7. Έλεγχος ότι δεν άλλαξαν οι υπολογισμοί

`tools/ui-regression/`:
```
pip install playwright && python -m playwright install chromium   # μία φορά
python tools/ui-regression/capture.py baseline.html base.json      # παλιά έκδοση
python tools/ui-regression/capture.py index.html new.json          # νέα έκδοση
python tools/ui-regression/compare.py base.json new.json           # exit 0 = ίδια
```
Καλύπτει 22 σενάρια (προεπιλογές, ψύξη/θέρμανση, 8 τυχαίους συνδυασμούς όλων των
πεδίων/presets, ομάδες υαλοστασίων, συσκευές, 3 χώροι, ψυχρομετρία με 4 συνδυασμούς,
EL/EN) και συγκρίνει: κείμενο όλων των περιοχών αποτελεσμάτων, όλες τις τιμές πεδίων,
τα pixels της πίτας και το κείμενο των 3 PDF (εκτός ημερομηνίας).

## 8. Γνωστά ανοιχτά θέματα

- Κάποιες ετικέτες του site είναι μόνο στα αγγλικά (π.χ. «Indoor Temp [degC]»). Ίσχυε
  και πριν· δεν άλλαξε για να μην αγγίξουμε τη λογική γλώσσας.
- Οι μονάδες είναι ακόμα μέσα στις ετικέτες «[m]». Στο σχέδιο είναι μέσα στο πεδίο.
  Θέλει wrapper γύρω από το `input`, και αυτό σπάει το `closest("div")` της βοήθειας
  πεδίων. Γίνεται σε επόμενο βήμα, με αλλαγή σε εκείνο το σημείο.
- Η ένδειξη «Σ = 100%» για οροφή/δάπεδο υπάρχει μόνο στο σχέδιο· στο site οι έλεγχοι
  μένουν στις γραμμές `#roofPctHint` / `#floorPctHint`.
- Οι γραμματοσειρές φορτώνονται από Google Fonts· χωρίς δίκτυο πέφτει στο fallback.
